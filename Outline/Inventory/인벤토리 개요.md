## 인벤토리 개요

#### 인벤토리는 총 3개의 Widget으로 구성되어있으며, 인벤토리 안에 있는 아이템의 설명을 도와주는 WB_CItemDescription Widget이 추가로 존재한다.

```
1. WB_Inventory
2. WB_InventorySlot
3. WB_EquipSlot
```
  ![image](https://github.com/user-attachments/assets/b5b2e7b7-a85e-409d-b9bf-3a30fbf3da0c)

  - WB_Inventory는 아이템을 담는 WB_InventorySlot과 장비창인 WB_EquipSlot으로 이루어져 있다.


```
WB_CItemDescription
```

  ![image](https://github.com/user-attachments/assets/1d52c8bf-00f2-422b-b114-b521fd7e69c8)

  - WB_CItemDescription는 WB_InventorySlot이나 WB_EquipSlot에 ItemData가 존재할 때 마우스를 올려놓는 OnMouseEnter 이벤트가 발생하면 아이템의 정보를 보여준다.
