## 아이템 구성

#### 아이템은 4가지 종류로 나뉘어져 있으며, ItemData를 관리하는 DataAsset에서 관리한다.

![image](https://github.com/user-attachments/assets/f1c1f7a3-bdbd-473f-ac92-82a71ba889c1)

```
Name : Item의 이름. 아이템 설명 위젯(WB_CItemDescription)을 위한 데이터 정보

Description : Item의 설명. 아이템 설명 위젯(WB_CItemDescription)을 위한 데이터 정보

Interact : 아이템과 상호작용(WB_Interact)할 때, 무기를 구분하기 위한 데이터 정보

ItemType : Item이 무기인지 다른 Type인지 구분해주는 데이터 정보

WeaponType : ItemType이 Weapon일 때 무기의 데이터 정보

WeaponClass : World에 스폰되어있는 DropItem Class 정보

CDropItemClass : Player가 Item을 장착하면 Spawn되는 Weapon Class의 정보

Picture : 아이템을 습득했을 때 InventorySlot에 들어갈 Texture 정보

WeaponIcon : 아이템을 장착했을 때 EquipSlot에 들어갈 Texture 정보
```
