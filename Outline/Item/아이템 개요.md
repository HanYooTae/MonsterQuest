## 아이템 개요

#### 아이템은 DataAsset으로 관리하고 있으며, DataAsset에는 다음과 같은 정보들이 존재한다.

#### 아이템 DataAsset은 Player와 Enemy가 공용으로 사용한다.

![image](https://github.com/user-attachments/assets/2457fe56-a3f1-4659-8cd6-648aa30b8bb6)
```
Weapon
 - 무기의 SkeletalMesh
 - 장착되었을 때 Player에게 붙을 Socket 정보
 - (ItemData)는 Player의 무기
 - (WeaponClass)는 Enemy가 사용할 무기
```

![image](https://github.com/user-attachments/assets/444f396f-aa00-425a-b344-556669507aa5)
```
Equipment
 - Player가 무기를 장착할 때 재생되는 몽타주
 - 몽타주 재생 속도
 - 움직일 수 있는지, 뒤돌아 볼 수 있는지 여부
```

![image](https://github.com/user-attachments/assets/3f52ece3-dffe-476f-8ae9-c2e739770d9f)
```
DoActions
 - Player가 무기를 장착한 후에 공격했을 때 재생되는 몽타주
 - 몽타주 재생 속도
 - 무기의 Damage
 - Combo
 - 움직일 수 있는지, 뒤돌아 볼 수 있는지 여부
 - 무기가 총기류일 경우, Spawn되는 총알
 - 무기가 총기류일 경우, 무기의 총알 갯수
```

![image](https://github.com/user-attachments/assets/f588942c-9865-4c8a-a5cf-09829ea68650)
```
Reload
 - 무기가 총기류일 경우, 재장전 시 재생되는 몽타주
 - 무기가 총기류일 경우, 재장전 시 탄창과 약실 Particle이 Spawn되는 BoneName
 - 움직일 수 있는지, 뒤돌아 볼 수 있는지 여부
```
