## 플레이어 개요

#### 플레이어의 모든 기능은 Widget을 기반으로 하고 있다.

```
PlayerHealthWidget
  - 사용자 정의 컴포넌트 중 StatusComponent의 CurrentHealth, MaxHealth를 기반으로 구성된 Widget
```
![image](https://github.com/user-attachments/assets/a1a6d492-2dd2-4db0-84b0-de876f3e9091)

```
InformationWidget
  - 좌측의 기능별 단축키를 알려주는 Widget
```
![image](https://github.com/user-attachments/assets/cf04650f-c00d-4b86-ad44-068d4f61d9f4)

```
CrossHairWidget
  - 총 무기를 장착하였을 때, 조준점 Widget
```
![image](https://github.com/user-attachments/assets/d4c21b42-568d-436e-8122-6937a16fa7f3)

```
HUD Widget
  - 총 무기를 장착하였을 때, 우측 하단의 무기 종류와 연사여부, 탄창에 남아있는 총알 갯수를 보여주는 Widget
```
![image](https://github.com/user-attachments/assets/d880c8ec-5e57-4b90-bcd5-882fd4dd6e1d)

Inventory Widget

Lose Widget
